## 📌 Sobre o Projeto

O **Portal de Notícias** é uma aplicação web estática estruturada com foco em boas práticas de semântica HTML5, arquitetura limpa de folhas de estilo CSS e navegação multi-página acessível e responsiva. O portal reúne matérias sobre o universo da programação, páginas temáticas de hobbies e página de perfil autoral.

---

## ✨ Funcionalidades

* **Estrutura 100% Semântica:** Utilização de tags semânticas do HTML5 (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<figure>`, `<footer>`).
* **Navegação Multi-página:**
  * `index.html`: Página principal com artigos sobre desenvolvimento web e tecnologia.
  * `hobbies.html`: Seção de interesses, esportes e lazer.
  * `perfil.html`: Página pessoal com biografia e trajetória acadêmica.
* **Estilização Modular:** Separação limpa com `reset.css`, `global.css` e `styles.css`.
* **Tipografia Moderna:** Integração com a fonte **Plus Jakarta Sans** via Google Fonts.
* **Layout Adaptável:** Otimizado para visualização em diferentes resoluções.

## 📁 Estrutura de Arquivos

```bash
portal-de-noticias/
├── css/
│   ├── reset.css       # Normalização de estilos padrão dos navegadores
│   ├── global.css      # Variáveis, fontes e regras globais
│   └── styles.css      # Estilização dos componentes e páginas
├── img/                # Imagens e ativos visuais
├── index.html          # Página principal do portal
├── hobbies.html        # Página sobre hobbies e interesses
├── perfil.html         # Página de perfil e biografia
└── README.md           # Documentação do projeto
```

## 🚀 Como Executar

1. Clone o repositório:
   ```bash
   git clone git@github.com:Academico-JZ/portal-de-noticias.git
   ```
2. Acesse o diretório:
   ```bash
   cd portal-de-noticias
   ```
3. Abra o arquivo `index.html` em qualquer navegador web moderno, ou utilize a extensão **Live Server**.
